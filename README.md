# 🤝 Telegram-ассистент маркетолога

Личный Telegram-бот для контроля задач, дедлайнов, клиентов и заметок — с ИИ-помощником
на базе Claude, который пишет тексты объявлений, придумывает офферы и отвечает на
маркетинговые вопросы прямо в чате.

Заточен под работу с контекстной рекламой (Яндекс Директ, Google Ads), таргетом
(Telegram Ads, VK Реклама, Авито) и клиентскими проектами.

## Возможности

- **📋 Задачи и дедлайны** — пошаговое создание, статусы (открыта / в работе / готово),
  привязка к клиенту. Дедлайн можно писать словами: «завтра», «пятница», «через 3 дня»,
  «15.03 14:00».
- **⏰ Напоминания** — бот сам напомнит, когда дедлайн наступил (проверка каждые 5 минут).
- **☀️ Утренний дайджест** — сводка задач на день приходит автоматически (время настраивается).
- **👥 Клиенты и проекты** — карточки с площадками, бюджетом, контактом; список задач по клиенту.
- **📝 Быстрые заметки** — пришли сообщение с `!` в начале, и оно сохранится (с `#тегами`),
  потом найдёшь поиском.
- **🤖 ИИ-помощник (Claude)** — генерация объявлений, заголовков, идей, разбор лендингов.
- **🔐 Роли и доступ** — только ты (владелец) и те, кому ты дал доступ. Команда и клиенты
  подтверждаются по кнопке.

## Быстрый старт

### 1. Создай бота в Telegram
Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи **токен**.

### 2. Узнай свой Telegram ID
Напиши [@userinfobot](https://t.me/userinfobot) — он пришлёт твой числовой **ID**.

### 3. Получи ключ Claude (для ИИ)
[console.anthropic.com](https://console.anthropic.com/) → Settings → API Keys → создай ключ.
_(Без ключа бот работает, но команды ИИ будут отключены.)_

### 4. Настрой и запусти

```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. Конфиг
cp .env.example .env
# открой .env и заполни BOT_TOKEN, OWNER_ID, ANTHROPIC_API_KEY

# 3. Запуск
python -m bot.main
```

Готово — напиши боту `/start`.

## Переменные окружения (`.env`)

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен бота от @BotFather |
| `OWNER_ID` | ✅ | Твой Telegram ID (владелец, полные права) |
| `ANTHROPIC_API_KEY` | — | Ключ Claude. Без него ИИ отключён |
| `ANTHROPIC_MODEL` | — | Модель ИИ. По умолчанию `claude-opus-4-8` (можно `claude-sonnet-5` — дешевле) |
| `TZ` | — | Часовой пояс. По умолчанию `Europe/Moscow` |
| `DIGEST_HOUR` | — | Час утреннего дайджеста (0–23). По умолчанию `9` |
| `DB_PATH` | — | Путь к файлу базы. По умолчанию `data/assistant.db` |

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Запуск / заявка на доступ |
| `/menu` | Показать кнопки меню |
| `/tasks`, `/addtask` | Список задач / новая задача |
| `/clients`, `/addclient`, `/client <номер>` | Клиенты |
| `/notes`, `/findnote <слово>`, `/delnote <номер>` | Заметки |
| `/ai <запрос>` | Быстрый вопрос к ИИ |
| `/digest` | Сводка на сегодня |
| `/users`, `/kick <ID>` | Управление доступом (только владелец) |
| `/help` | Справка |

Быстрая заметка: любое сообщение, начинающееся с `!`, сохраняется как заметка.

## Как дать доступ команде или клиенту

1. Человек пишет боту `/start` → бот отправляет тебе заявку.
2. Ты жмёшь кнопку: **в команду** (полный доступ к задачам/заметкам) или **как клиента**
   (ограниченный доступ).
3. Убрать доступ: `/kick <ID>` (ID виден в `/users`).

## Архитектура

```
bot/
├── main.py          # точка входа: бот, БД, планировщик, polling
├── config.py        # конфигурация из .env
├── db.py            # SQLite (aiosqlite): пользователи, клиенты, задачи, заметки
├── ai.py            # интеграция с Claude API
├── keyboards.py     # клавиатуры (меню, инлайн-кнопки)
├── middlewares.py   # контроль доступа
├── scheduler.py     # напоминания и дайджест (APScheduler)
├── reports.py       # сборка сводок
├── utils.py         # парсинг дедлайнов, форматирование
└── handlers/        # обработчики: access, common, tasks, clients, notes, ai_chat
```

**Стек:** Python 3.11+, [aiogram 3](https://docs.aiogram.dev/), aiosqlite, APScheduler,
[anthropic SDK](https://github.com/anthropics/anthropic-sdk-python).

## Mini App (веб-интерфейс)

Кроме чата, у бота есть Mini App — доска задач внутри Telegram (вкладки «Задачи /
Клиенты / Заметки», создание задач, смена статусов). Веб-сервер поднимается в том же
процессе (`bot/web.py`), интерфейс — `bot/webapp/index.html`. Авторизация — по подписи
Telegram `initData`, доступ только у пользователей бота.

Чтобы кнопка приложения появилась, задай `WEBAPP_URL` (публичный HTTPS-адрес хостинга)
и привяжи Mini App у @BotFather (`/newapp` или Bot Settings → Menu Button).

## Деплой

В репозитории есть `Dockerfile` — любая платформа соберёт проект сама.
Есть готовые конфиги: `render.yaml` (Render, деплой в один клик) и `amvera.yml` (Amvera).

### Вариант 1 — Render (в один клик, есть кнопка)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/dkaratsapov-web/assistant)

Клик по кнопке → авторизуешь GitHub → Render читает `render.yaml` → просит ввести
`BOT_TOKEN` и `OWNER_ID` → деплоит и выдаёт HTTPS-адрес. Затем впиши этот адрес в
переменную `WEBAPP_URL` и привяжи Mini App у @BotFather.

### Вариант 2 — Railway / Amvera / другой PaaS

Подходят Railway, Amvera, Timeweb Cloud Apps, Fly.io и т.п.

Общий порядок (без терминала, только веб-панель):
1. Подключить GitHub-репозиторий к платформе, тип сборки — Docker.
2. Задать переменные окружения: `BOT_TOKEN`, `OWNER_ID` (и `ANTHROPIC_API_KEY` при
   необходимости). Для постоянной базы — примонтировать диск и указать
   `DB_PATH=/data/assistant.db`.
3. Задеплоить → платформа выдаст HTTPS-адрес.
4. Прописать этот адрес в `WEBAPP_URL`, передеплоить.
5. У @BotFather привязать Mini App к боту (Menu Button → этот адрес).

Для Amvera уже есть `amvera.yml` (постоянный диск на `/data`, порт 8080).

> Если хостинг в РФ режет Telegram — задай `TELEGRAM_API_URL` (свой прокси на
> Cloudflare Workers) или `PROXY_URL` (зарубежный SOCKS5). См. `.env.example`.

### Локальный запуск (для разработки)

```bash
pip install -r requirements.txt
cp .env.example .env      # заполни BOT_TOKEN и OWNER_ID
python -m bot.main
```
