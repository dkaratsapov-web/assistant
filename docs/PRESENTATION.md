# Assistant Sara — презентация для продажи по подписке

> Рабочий черновик. Пополняется по ходу разработки. **Не для выдачи до отдельного распоряжения.**

## 1. Что это
AI‑ассистент в Telegram (бот + Mini App) для предпринимателей, самозанятых, маркетологов и активных людей. Управление задачами, встречами, клиентами и личным здоровьем — голосом, текстом и кнопками. Внутри — Claude (умные ответы, генерация контента и документов) и Yandex SpeechKit (распознавание речи).

## 2. Целевая аудитория
- Маркетологи / SMM / фрилансеры (ведение клиентов, отчёты, контент).
- Малый бизнес и самозанятые (задачи, встречи, документы, деньги).
- Широкая ЦА ЗОЖ (калории, вода, вес, привычки).

## 3. Что уже сделано (функционал)
**Продуктивность**
- Задачи (рабочие/личные, приоритеты, статусы, дедлайны, напоминания).
- Встречи/календарь: режим «Список» и «Месяц», встречи + задачи вместе.
- Контакты и дни рождения с тегами, напоминания заранее.
- Утренний брифинг (сводка дня).

**AI‑ассистент (Сара)**
- Ответы на любые вопросы (как Claude), не только маркетинг.
- Голосовой ввод (в боте и в приложении).
- Генерация документов Word (.docx): КП, отчёты, письма.
- Распознавание команд голосом/текстом (создать/выполнить/удалить задачу, встречу, контакт, заметку).

**Клиенты / маркетинг**
- Мини‑CRM: клиенты, площадки, бюджет, сумма и дедлайн оплаты ведения.
- Отчёты Яндекс Метрики по клиенту (визиты, посетители, отказы, источники) + выгрузка в Word.
- Интеграция Яндекс Телемост (авто‑ссылка на видеовстречу).

**Здоровье**
- Питание с оценкой калорий и БЖУ через ИИ (текст, голос, **фото блюда** — vision).
- Приёмы пищи: завтрак/обед/ужин/перекус с подытогами; частые блюда в 1 тап.
- Вода: учёт, быстрые кнопки, авто‑норма по весу, напоминания.
- Вес с графиком, БЖУ‑цели с прогрессом, стрик, недельная сводка.
- Заметки о самочувствии, рекомендации и меню на день от ИИ.
- **Сводка по питанию за день** для пересылки тренеру (текст/копия/команда).
- **Календарь БАДов/фармы**: курсы, чек‑лист на день, адхеренс за неделю, напоминания по времени.
- **Активность/шаги** + сожжённые калории и баланс «съел/потратил».
- **Сон и настроение** (быстрые отметки).
- **Экспорт дневника питания** в Word (`/foodexport`).
- Гибкие уведомления (брифинг, задачи, встречи, ДР, вода, приёмы пищи) — на пользователя.

**Экономика/техника**
- Локальный разбор частых команд = 0 токенов; распознавание на дешёвой модели + кеш промптов.
- Cloudflare Workers + D1 (SQLite), крон‑планировщик, авто‑миграции.
- Автотест интерфейса (headless‑браузер) перед релизами.

## 4. Плюсы
- Всё в Telegram — не нужно ставить отдельное приложение.
- Голос + фото + текст + кнопки: минимум трения.
- Узкие интеграции под РФ (Метрика, Телемост, Директ — в планах), которых нет у общих ботов.
- Низкая себестоимость на пользователя (оптимизация токенов) → высокая маржа.
- Быстрая итерация, покрытие автотестом.

## 5. Минусы / ограничения (честно)
- Instagram/TikTok аналитика ограничена (API Meta в РФ).
- Чек НПД в «Мой налог» требует партнёрства с ФНС или банка‑партнёра.
- Пока однопользовательский контур; для продажи нужна мультиарендность и биллинг.
- Директ‑отчёты и часть здоровья (активность, сон) — в доработке.
- Зависимость от сторонних API (Anthropic, Yandex) и их лимитов/цен.

## 6. Монетизация (ориентиры рынка РФ)
- Подписка: Фрилансер 490–1 490 ₽/мес, Про 1 490–3 500 ₽/мес, Команда 3 000–9 000 ₽/мес.
- Whitelabel/внедрение агентствам: 50 000–250 000 ₽ разово.
- Модель: гибрид (подписка + внедрение). Оплата — Telegram Stars/ЮKassa.

## 7. Дорожная карта
- Мультиарендность + биллинг (Stars/ЮKassa), онбординг.
- Отчёты Яндекс Директ; аудит соцсетей (точки роста).
- Финансы лайт (доходы/расходы голосом).
- Лендинг с тарифами.

## 8. Демо‑сценарии для показа
- «Съел борщ с хлебом» / фото тарелки → калории и БЖУ в дневник.
- «Отчёт по клиенту Ромашка» → сводка Метрики + Word‑файл.
- «Добавь встречу завтра в 15 с Телемостом» → событие со ссылкой.
- «Сделай КП по настройке Директа» → готовый .docx.
